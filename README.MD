\# Retail Sales Dashboard



An interactive \*\*Retail Sales Dashboard\*\* created in Microsoft Excel to analyze sales performance, customer behavior, product categories, and demographic trends.



\## Dataset



The dataset used for this project was obtained from Kaggle:



https://www.kaggle.com/code/hbsaakashyadav/retail-sales-dataset/input



The dataset contains retail transaction information used to analyze revenue, orders, quantities, customers, product categories, age groups, and gender.

\## Objective



The objective of this project is to transform raw retail transaction data into a clear and easy-to-understand dashboard that can be used to identify \*\*sales performance, customer trends, and product category performance\*\*.
